# 电表异常原因分析指南

## 适用场景

当监控电表（或其他类型电表）出现日电量持续超标时，需分析异动原因并生成报告。

## 三种异动模式

| 模式 | 特征 | 典型原因 |
|---|---|---|
| 长期持续型 | 月电量从基线就超标，持续数月甚至数年 | 线路长期带病运行（早期雷击破损未修复），可能叠加二次雷击恶化 |
| 夏季突发型 | 基线平稳，某日突飙后持续数十天 | 雷击/暴雨导致线路绝缘破损接地 |
| 滞后突发型 | 基线平稳，暴雨结束后数天至数周才突飙 | 雨水渗入破损处后逐步劣化，或台风后残留环流带来雷电 |

## 分析流程

### Step 1: 抓取日级数据

对异动户号逐月调用 `fetch_month(cfg, year_month, price, cls_map)` 抓取每日电量（含温度）。
- 至少覆盖异动起始前6个月至恢复后1个月
- 同时抓取同地区正常户做对照

### Step 2: 识别异动段

```python
# 基线 = 正常日（日电量 ≤ 阈值）
# 异动段 = 连续超标日期段
segments = []
seg_start = None
for i, r in enumerate(data):
    p = float(r['用电量(千瓦时)'])
    if p > threshold and seg_start is None:
        seg_start = i
    elif p <= threshold and seg_start is not None:
        segments.append((seg_start, i-1))
        seg_start = None
```

每个异动段记录：起始日、恢复日、持续天数、日均电量、最高电量。

### Step 3: 恢复机制判定

查看恢复前2天的数据：
- **有过渡日**（电量降至异动值与基线之间的中间值，如 40度→18度→0.6度）→ 自然恢复（接地电阻随土壤湿度变化）
- **无过渡日**（直接从40度跳到0度或基线）→ 可能是人为断电修复
- **恢复后≠0度** → 供电未中断，仅漏电消失

### Step 4: 天气事件关联

用 `online_search` 搜索异动起始日前后所在地区的天气：
- 关键词：`所在地区 YYYY年M月 雷暴 雷电 暴雨 雷雨大风 预警`
- 重点关注：雷电黄色/橙色预警、暴雨橙色/红色预警、雷雨大风预警
- 逐户对照异动起始日与天气事件日期

### Step 5: 经济损失估算

从电费台账文件提取月度电量台账，计算：
- 异动月电量 - 基线月电量 = 异增电量
- 异增电量 × 平均电价 ≈ 异增电费
- 增幅 = (异动月电量 - 基线月电量) / 基线月电量 × 100%

### Step 6: 生成 HTML 报告

使用 `html-generator` 技能生成报告，推荐 mode-doc 模式 + 墨蓝调色板。

报告结构：
1. 概述（异动户数、时间范围、数据来源）
2. 异动电表概况（表格：编号/地址/所属区域/地理特征）
3. 异动时间线与天气对照（三种异动模式卡片 + 起始日vs天气表格 + 天气事件时间线 + 长期异动户专题）
4. 恢复机制分析（过渡日表格 + 下电vs自然恢复对比 + 物理过程）
5. 原因分析（因果链 + 证据链列表 + 经济损失表格）
6. 结论与建议（结论列表 + 建议列表 + 安全风险提示）
7. 数据来源（cite + source-list 配对）
8. 尾页（署名）

## 因果链（线路破损接地型）

```
雷电/暴雨
  ↓
户外监控线路绝缘层被雷击穿或雨水侵入破损处
  ↓
线路接地故障（接地电阻随土壤湿度变化）
  ↓
漏电电流持续流过（非设备负载，是接地回路电流）
  ↓
日电量从0.4-0.6度基线飙升至40-60度
  ↓
持续数十天（雨季土壤潮湿，接地电阻低，漏电持续）
  ↓
天气转干（连续晴天）
  ↓
土壤水分蒸发，接地电阻急剧增大
  ↓
过渡日：漏电电流减半（40度→18度）
  ↓
次日：接地电阻足够大，漏电几乎消失（18度→0.6度）
  ↓
恢复到正常监控基线
```

## 关键证据模式

1. **时间关联**：每户异动起始日均出现在一次雷电/暴雨事件之后
2. **恢复特征**：有过渡日、恢复后≠0度、各户恢复日各不相同（非统一断电）
3. **用电量特征**：日内波动极小（稳定漏电），不像设备有启停波动
4. **地理特征**：异动户全在水体旁开阔地（雷击高发点位）
5. **对照实验**：同地区同期间其他正常户运行正常
6. **现场确认**：线路破损接地或设备接地
