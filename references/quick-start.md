# 南网电表哨兵 - 快速上手指南（面向新用户）

> 本指南面向从技能市场安装本技能的用户，覆盖从零开始到日常使用的全部场景。所有操作只需与 AI 对话完成，无需手动改代码。

## 一、你需要准备什么

| 项目 | 说明 | 获取方式 |
|---|---|---|
| 南网在线账号 | 手机号注册即可，无费用 | https://95598.csg.cn |
| 电表户号 | 要监控的电表 16 位用户编号（电费账单上有） | 供电局账单/清单 |
| 代扣银行卡后6位 | 户号不在本人名下时需要（验证凭据） | 该户号登记的代扣银行卡 |
| 飞书群机器人 Webhook | 可选，用于接收超标提醒 | 飞书群设置→群机器人→自定义机器人 |

**账号限制**：单个南网账号最多绑定 26 户电表。监控更多户需准备多个账号，或多轮解绑/重绑。

## 二、首次配置

提供两种模式，根据你的情况选择：

### 模式 A：全自动配置（推荐，约 15 分钟）

> AI 用浏览器自动操作，你只需提供信息 + 配合 1 次验证码。适合不想手动操作的同事。

**你只需提供以下信息**（一次性发给 AI）：

| 信息 | 必需 | 说明 |
|---|---|---|
| 手机号 | 是 | 南网在线登录手机号 |
| 电表户号清单 | 是 | 16 位用户编号，多个用逗号或换行分隔 |
| 代扣银行卡后 6 位 | 看情况 | 户号不在本人名下时必需（如公司电表），本人名下可不提供 |
| 飞书 Webhook | 可选 | 想收飞书提醒时提供；需你先在飞书群建机器人 |

**对 AI 说**："**全自动配置南网电表哨兵，手机号是 13xxxxxxxxx，户号是 1234567890123456（示例），银行卡后6位是 xxxxxx**"

AI 自动执行：
1. **自动打开登录页**：Playwright 打开 95598.csg.cn，自动填入手机号，点击发送验证码
2. **你配合 1 次**：手机收到验证码后告诉 AI（如"验证码是 123456"），AI 自动填入并登录
3. **自动提取 Token**：登录成功后 AI 从页面自动读取 token 和 custNumber，写入 config.json（**你不需要 F12**）
4. **自动逐户绑定**：AI 导航到户号绑定页，自动填用户编号 + 银行卡后6位，逐户查询并绑定（每户约 30 秒）
5. **自动同步户号信息**：AI 调接口获取所有 bindingId，自动识别电表类型，写入 config.json
6. **写入飞书配置**：你提供 Webhook 地址后 AI 自动写入
7. **自动部署定时任务**：AI 创建 Windows 计划任务（每天 09:00）
8. **试运行验证**：AI 立即抓取一次，确认链路正常

**全程你只需 3 次互动**：
- 提供信息（手机号 + 户号 + 银行卡后6位）
- 报一次验证码
- 提供飞书 Webhook（可选）

### 模式 B：手动配置（约 10 分钟，已有经验或偏好自己操作）

对 AI 说："**配置南网电表哨兵**"，按以下步骤逐项完成：

#### 第 1 步：登录南网在线

1. 浏览器打开 https://95598.csg.cn
2. 手机号 + 短信验证码登录（未注册先注册）

#### 第 2 步：提取 Token

登录后按 F12 打开控制台，Console 页粘贴执行：

```javascript
copy(sessionStorage.getItem('token') + '|' + sessionStorage.getItem('custnumber'))
```

剪贴板即获得 `token|custNumber` 格式的凭证，告诉 AI"token 已复制"，AI 会引导你写入 config.json。

#### 第 3 步：绑定电表户号

网页上操作（南网在线 → 我的 → 户号绑定）：

- **户号在你手机号名下** → 选「手机号查询」→ 勾选未绑户号 → 立即绑定（单次约 10 户）
- **户号不在你名下**（如防溺水监控、基站等）→ 选「用户编号验证」→ 填 16 位用户编号 + 该户代扣银行卡后 6 位 → 立即查询 → 勾选 → 立即绑定

绑定完成后对 AI 说："**绑定已完成，请同步户号**"，AI 会调用接口获取最新 bindingId 写入 config.json。

> 注意：bindingId 每次登录/刷新后可能变化，AI 会在每次操作前动态获取，你无需关心。

#### 第 4 步：配置飞书提醒（可选）

1. 在你自己的飞书群：设置 → 群机器人 → 添加自定义机器人
2. 复制 Webhook 地址，对 AI 说："飞书 webhook 是 https://xxx"
3. **只使用你自己创建的机器人，不要使用任何第三方提供的地址**

#### 第 5 步：确认告警阈值（异动阈值）

默认按电表类型差异化告警，不设定时自动启用：

| 电表类型 | group 键名 | 日电量异动阈值 | 设定依据 |
|---|---|---|---|
| 防溺水监控 | fangnishui | **1.5 度** | 日用电基线 ×3 |
| 基站 | base_station | **25 度** | 日用电基线 ×3 |
| 接入网机房 | access_room | **85 度** | 日用电基线 ×3 |
| 综合机房 | comprehensive_room | **717 度** | 日用电基线 ×3 |
| 治安视频监控 | security_monitor | **1.5 度** | 日用电基线 ×2.5 |

**设定逻辑**：阈值 ≈ 正常日均用电量 × 3 倍。超过即判定异动（可能漏电、窃电、设备异常）。正常电表不会误报，异常电表不会漏报。

**三种告警模式**：

| 模式 | 含义 | 适用 |
|---|---|---|
| both（默认） | 电量超标 或 电费超标任一提醒 | 通用 |
| power_only | 仅看日电量是否超标 | 只关注用电异动，不关心电费 |
| fee_only | 仅看日估算电费是否超标 | 按费用管控 |

**调整方式**（对话即可，无需改代码）：

| 你说 | AI 执行 |
|---|---|
| 基站阈值改成 30 度 | 修改 meter_groups 中基站分类阈值 |
| 全部按 2 度告警 | 临时用 --alert-power 2 全局覆盖 |
| 只看电量不看电费 | 改 alert_threshold.mode 为 power_only |
| 新增一个机房分类阈值 500 度 | 在 meter_groups 中新增自定义分类 |

> 已实机验证：正常户零误报，异常户（如雷击/暴雨致线路漏电）能准确检出并推送告警。具体户号与阈值请按实际绑定户号配置。

## 三、日常使用

### 对话触发（最常用）

| 你说 | AI 执行 |

| "抓9月的电量" | 指定月份 |

| "更新南网token" | 引导你重新提取 token |
| "基站阈值改成 30 度" | 调整异动阈值 |
| "全部按 2 度告警" | 临时全局覆盖异动阈值 |
| "只看电量不看电费" | 改告警模式为 power_only |

### 定时任务（推荐）

对 AI 说："**部署南网每日抓取定时任务**"，AI 会创建 Windows 计划任务（每天 09:00 自动运行），后续无需人工干预。

### 输出文件

每次抓取自动落盘 Excel 到 config.json 同目录：

- 文件名：`南网每日电量_YYYYMM.xlsx`
- 表头：用户编号 / 电表类型 / 用电地址 / 日期 / 用电量 / 估算电费 / 最低温 / 最高温 / 均温

## 四、常见场景速查

### 场景 1：Token 失效了

**现象**：飞书收到"登录失效"提醒，或抓取无数据。

**处理（全自动模式）**：对 AI 说"南网token失效了"，AI 自动打开浏览器登录页填手机号，你报一次验证码，AI 自动提取新 token 写入配置。

**处理（手动模式）**：
1. 重新登录 https://95598.csg.cn
2. F12 控制台执行第 2 步的 copy 命令
3. 对 AI 说："更新南网token"，粘贴剪贴板内容

**说明**：token 跨日有效，失效周期约数天到数周，属正常现象。

### 场景 2：换了手机号

手机号是南网在线登录账号本身，处理顺序：

1. 到 95598.csg.cn「账户安全」改绑手机号（或新手机号注册）
2. 新号重新登录，对 AI 说"全自动配置"，AI 自动提取新 Token
3. **之前绑定的户号不会丢失**（户号绑定在账号体系下，与手机号变更无关）

### 场景 3：想监控新的电表

**全自动模式**：对 AI 说"绑定新户号 1234567890123456（示例），银行卡后6位 xxxxxx"，AI 自动打开浏览器逐户绑定并同步。

**手动模式**：
1. 网页端绑定新户号（方式同模式 B 第 3 步）
2. 对 AI 说："**绑了新户号，请同步并更新分类**"
3. AI 自动识别电表类型（按 meter_classification.json 分类映射表），套用对应阈值

### 场景 4：不想监控某些电表了

对 AI 说："**解绑这几个户号**"，AI 调用解绑接口批量处理。

**注意**：网页端无解绑入口，此操作只能通过 AI 完成（调 API）。解绑后绑定户数释放，可绑其他户。

### 场景 5：绑定户号已满 26 户

单账号上限 26 户。两种方案：

- **方案 A**：解绑不优先监控的户，释放名额给重点户
- **方案 B**：用另一个手机号注册新南网账号，对 AI 说"全自动配置"重复首次配置流程

### 场景 6：数据好像不是最新的

电量数据为 **T+3 发布**（如 10 月 1 日用电量最迟 10 月 4 日可查）。月初 1-3 日查本月可能无数据，脚本会自动回退抓上月，属正常设计。

### 场景 7：换电脑使用

config.json 是全部配置。对 AI 说："**迁移配置**"，AI 引导你把 config.json 复制到新机器并重新部署定时任务。

## 五、多用户独立运行说明

本技能每个用户的数据完全独立，互不干扰：

| 数据 | 归属 | 存放位置 |
|---|---|---|
| 南网账号/Token | 各自 | 各自 config.json |
| 绑定户号 | 各自南网账号下 | 南网服务器 |
| 飞书推送 | 各自群机器人 | 各自 config.json |
| 告警阈值 | 各自配置 | 各自 config.json |
| 抓取结果 | 各自 | 各自 Excel |

一人配置只影响自己，团队可各自安装、各自监控各自责任区的电表。

## 六、常见问题

| 问题 | 答案 |
|---|---|
| 需要编程基础吗 | 不需要，全部对话完成 |
| 会泄露我的电费数据吗 | 数据全程在你本机处理，只与你自己的飞书机器人通信 |
| 抓取会消耗流量吗 | 每日一次轻量 API 调用，忽略不计 |
| 能监控南网五省各地的电表吗 | 接口为南网五省通用，脚本默认带一个已验证区域代码；其他地区需修改 areaCode |
| 支持多少种电表分类 | 防溺水/基站/接入网机房/综合机房/治安监控 5 类内置阈值，可自定义扩展 |
| token多久失效 | 数天到数周不等，失效后 10 秒可续期 |
| 全自动配置时 AI 需要什么 | 仅需手机号 + 户号 + 银行卡后6位 + 1 次验证码 |
| 全自动模式会操作我的浏览器吗 | 会打开 95598 网页自动填表，只读不写账户设置 |
| 同事能一键配置吗 | 能，各自提供各自信息，AI 逐个全自动配置 |
